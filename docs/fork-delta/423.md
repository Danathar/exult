# [#423](https://github.com/Danathar/exult/pull/423)

- **Files:** `shapes/vgafile.cc`
- **Reason:** The RLE painters (`Image_buffer8::paint_rle` and its variants, `Shape_frame::has_point`) walk a frame's scanlines until a zero scanline word without knowing the buffer length, so a frame from a save screenshot, a mod or a `.shp` file with a missing terminator, a raw scanline past the end or an encoded run longer than its scanline made them read past the heap buffer (#422). `get_rle_shape()` now checks the data with `rle_data_fits()` and loads a bad frame as an empty `{0,0}` frame, as `read()` already does for bad offsets. At sync time keep this if upstream's `get_rle_shape()` still copies the frame bytes without checking the scanlines against `datalen`
- **Upstream status:** not reported
