# [#377](https://github.com/Danathar/exult/pull/377)

- **Files:** `cheat.cc`, `files/utils.cc`, `files/utils.h`
- **Reason:** The Exult Studio launch command in `Cheat::toggle_map_editor()` carried a mod's title unquoted into `system()`, so a hostile mod could run shell commands. Every value on that command line is now quoted by `quote_posix_shell_arg()` or `quote_windows_arg()`. At sync time keep this quoting if upstream's launch code has not changed it
- **Upstream status:** not reported
