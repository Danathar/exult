# Docs section map: every section of every tracked documentation page, and
# whether a test reads it.
#
# A page lists here as [path]. Under it, every `##` and `###` heading of that
# page, written exactly as the page writes it, followed by one indented line:
#
#   joined: <test file>    that test reads what this section states
#   prose: <reason>        no test reads it, and this says why that is fine,
#                          or names what is left unchecked
#
# scripts/tests/docs-section-map.test.mjs fails when a tracked page has a
# heading with no row here, when a row names a heading the page no longer has,
# or when a `joined:` file is not a check CI runs or never opens the page. It
# does not prove any sentence true. What it changes is that a section of claims
# about the build, the workflows or the agent tooling that nothing checks is a
# visible `prose: unchecked` line in the diff that adds it, instead of the
# silent default.
#
# `prose: unchecked:` marks a section that states facts about the machine (a
# workflow, a script, the ruleset, the settings file, the Bash guard, the
# policies) that no test reads. Each is a candidate for a join test; turning it
# into `joined:` is the fix. `prose: narrative:` marks a section that states no
# such fact.
#
# Tracked pages: every tracked Markdown file at the repository root, in docs/
# and in docs/security/ (not the dated metrics, agent-task, reflection and
# fork-delta ledgers), plus .github/copilot-instructions.md, except the copies
# of upstream pages the test names in UPSTREAM_PAGES. A new page in one of those
# places has to be added here, or to UPSTREAM_PAGES if upstream owns it, in the
# change that adds it.
